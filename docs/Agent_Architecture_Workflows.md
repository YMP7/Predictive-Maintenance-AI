# ATLAS: Specialized Agent Architecture & Workflow Specifications

This document details the architectural structure, mathematical transformations, and internal pipeline stages for the three core agents operating within the **ATLAS Multi-Agent Cognition System**:
1. **World Model Agent (Attention-LSTM)** — Temporal feature perception, multitask prognostics, and 32-dim latent embedding generation.
2. **AMKB Memory & Explainability Agent (XAI)** — Episodic failure precedent retrieval ($k=5$) and 14-pass contrastive occlusion feature attribution.
3. **Simulation & Decision Support Agent (Decision Graph)** — 1,000-draw Monte Carlo degradation rollout, lead-time modeling, and asymmetric economic risk optimization.

---

## 1. World Model Agent (Attention-LSTM)

The **World Model Agent** acts as the primary perceptual encoder. It continuously processes incoming 30-timestep multivariate operational windows, tracks non-linear degradation trends across temporal states, and outputs prognostic estimates alongside an invariant 32-dimensional latent embedding.

![World Model Agent (Attention-LSTM) Architecture & Workflow](C:/Users/yegir/.gemini/antigravity-ide/brain/1b511b9c-f07b-4d8b-af6b-569b67777f2f/world_model_agent_1790520508589.jpg)

### Internal Workflow Stages:
1. **Input Telemetry Windowing**:
   - Ingests temporal matrix $X = [x_1, \dots, x_{30}]^T \in \mathbb{R}^{30 \times D}$ ($D=14$ for C-MAPSS, $D=5$ for compute domains).
2. **2-Layer Recurrent LSTM Encoder**:
   - Sequential recurrence through stacked hidden units ($H=64$, dropout $p=0.20$):
     $$h_t, c_t = \text{LSTM}(x_t, (h_{t-1}, c_{t-1})), \quad t \in \{1, \dots, 30\}$$
3. **Temporal Attention Pooling**:
   - Computes alignment energies $e_t = v_a^\top \tanh(W_a h_t + b_a)$ and softmax weights $\alpha_t = \frac{\exp(e_t)}{\sum_j \exp(e_j)}$.
   - Dynamically concentrates representational focus on degradation transition points.
   - Context synthesis: $c_{\text{attn}} = \sum_{t=1}^{30} \alpha_t h_t \in \mathbb{R}^{64}$.
4. **Context Bottleneck (Latent Projection)**:
   - Projects context into an invariant latent state: $z = \text{LayerNorm}(W_z c_{\text{attn}} + b_z) \in \mathbb{R}^{32}$.
   - Verified by the non-collapse variance guard $\sigma(z) \ge 0.05$.
5. **Multi-Head Tri-Output**:
   - **RUL Prediction Head**: $\hat{y}_{\text{RUL}} = \max\left(0.0, \; W_2 \cdot \text{Mish}(W_1 z + b_1) + b_2\right)$.
   - **Health / Stress Head**: $h = \sigma(W_h z + b_h) \in [0.0, 1.0]$.
   - **Episodic Latent Routing**: Dispatches $z \in \mathbb{R}^{32}$ directly to the AMKB Vector Database.

## 2. AMKB Memory & Explainability Agent (XAI)

The **AMKB Memory & Explainability Agent** grounds model inferences in historical run-to-failure precedent cases and provides real-time sensor root-cause attribution without circular reasoning.

![AMKB Memory & Explainability Agent Architecture & Workflow](C:/Users/yegir/.gemini/antigravity-ide/brain/1b511b9c-f07b-4d8b-af6b-569b67777f2f/explainability_memory_agent_1790520549923.jpg)

### Internal Workflow Stages:
1. **Latent Query Ingestion**:
   - Receives the 32-dimensional query vector $z_q \in \mathbb{R}^{32}$ generated by the World Model Agent.
2. **pgvector Angular Cosine Retrieval Engine**:
   - Executes nearest-neighbor search across the TimescaleDB `pgvector` store using the `<=>` cosine distance operator:
     $$\mathcal{D}_{\cos}(z_q, v_i) = 1.0 - \frac{z_q \cdot v_i}{\|z_q\|_2 \|v_i\|_2}$$
   - Retrieves top-$k=5$ historical precedents $\mathcal{N}_k$ with observed ground-truth lifespans `true_rul` (strictly non-circular).
3. **14-Pass Contrastive Occlusion Analyzer**:
   - Occludes each sensor channel $j \in \{1, \dots, D\}$ with domain baseline mean $\bar{x}_j$:
     $$\Delta y_j = |f(X) - f(X_{\setminus j})|$$
4. **Root-Cause Feature Attribution**:
   - Normalizes sensitivity deltas into relative percentage contributions:
     $$\phi_j = \left(\frac{\Delta y_j}{\sum_{m=1}^D \Delta y_m}\right) \times 100\%$$
   - Maps top features to physical subsystems (e.g., *HPC Outlet Temperature: 34.2%*, *Core Thermal Throttling: 26.1%*).
5. **Variance-Penalized Epistemic Confidence Calibration**:
   - Evaluates similarity against precedent trajectory dispersion:
     $$\mathcal{C} = \bar{s} \times \left(\frac{1.0}{1.0 + \sigma^2_{\text{AMKB}} + 10^{-4}}\right)$$
   - High similarity + low neighbor outcome variance $\implies$ high epistemic confidence ($r_s = -0.5090$).
6. **Grounded Explanation Report**:
   - Assembles verified historical case citations, top failure sensors, and calibrated confidence score into the final audit card.

## 3. Simulation & Decision Support Agent (Decision Graph)

The **Simulation & Decision Support Agent** translates prognostic forecasts into risk-optimized maintenance actions by evaluating economic costs across stochastic Monte Carlo degradation trajectories.

![Simulation & Decision Support Agent Architecture & Workflow](C:/Users/yegir/.gemini/antigravity-ide/brain/1b511b9c-f07b-4d8b-af6b-569b67777f2f/decision_simulation_agent_1790520576819.jpg)

### Internal Workflow Stages:
1. **Prognostic Uncertainty Ingestion**:
   - Ingests point estimate $\hat{y}$ and empirical neighborhood variance $\sigma^2_{\text{AMKB}}$.
2. **1,000-Draw Monte Carlo Simulation**:
   - Samples $N = 1,000$ stochastic lifecycle realizations:
     $$y^{(m)} \sim \mathcal{N}\left(\hat{y}, \; \max(\sigma^2_{\text{AMKB}}, 10^{-6})\right), \quad y^{(m)} \in [0.0, 125.0]$$
3. **Action Lead-Time Matrix ($\tau(a)$)**:
   - Evaluates candidates against operational logistical horizons:
     - $\text{CONTINUE\_OPERATION}$ ($\tau = 30$ cycles review horizon)
     - $\text{SCHEDULE\_MAINTENANCE\_SOON}$ ($\tau = 10$ cycles lead time)
     - $\text{SCHEDULE\_MAINTENANCE\_NOW}$ ($\tau = 3$ cycles lead time)
     - $\text{REPLACE\_IMMEDIATELY}$ ($\tau = 0$ cycles lead time)
4. **Asymmetric Economic Cost Engine**:
   - Assesses failure penalty vs. scheduled intervention cost:
     $$C(y^{(m)}, a) = \begin{cases}
     C_{\text{unplanned}} = \$1,000.0, & \text{if } y^{(m)} \le \tau(a) \\
     0.0, & \text{if } y^{(m)} > \tau(a) \text{ and } a = \text{CONTINUE} \\
     C_{\text{base}} + C_{\text{downtime}} \cdot \mu_{\text{urgency}}(a), & \text{if } y^{(m)} > \tau(a) \text{ and } a \ne \text{CONTINUE}
     \end{cases}$$
5. **4-Tier Deterministic Safety Cascade & DEF-008 Override**:
   - Ranks candidates via deterministic priority tuple:
     $$\text{sort\_key}(a) = \Big(\mathbb{E}[C(a)], \; -p_{\text{fail}}(a), \; \sigma_C(a), \; \text{name}(a)\Big)$$
   - Enforces DEF-008 Zero-Miss Safety Parity Constraint:
     $$\text{if } \hat{y} \le 10 \text{ cycles} \quad \text{or} \quad h \le 0.20 \implies a^* \leftarrow \text{REPLACE\_IMMEDIATELY}$$
6. **Prescribed Maintenance Decision Output**:
   - Dispatches recommended intervention ($a^*$), expected monetary cost ($\mathbb{E}[C]$), failure risk ($p_{\text{fail}}$), and work order sign-off.

### Internal Hub Mechanisms:
1. **Asynchronous Parallel Dispatch**:
   - Dispatches operational window $X \in \mathbb{R}^{30 \times D}$ simultaneously across the `WorldModelAgent`, `DNAPerfilingAgent`, `RULPredictorAgent`, and `AMKBMemoryAgent`.
   - Preserves end-to-end quiescent latency between **$20.79\text{--}36.34$ ms ($p_{50}$)** under non-blocking execution.
2. **Shared Cognitive Memory Bus**:
   - Transports the canonical 32-dimensional invariant latent vector $z \in \mathbb{R}^{32}$ across heterogeneous subsystem boundaries without re-computation or domain schema leakage.
3. **Multi-Criteria Result Fusion**:
   - Assembles the compound cognitive state vector:
     $$\Psi = \left\langle z \in \mathbb{R}^{32}, \; \mathbf{z}_{\text{DNA}} \in \mathbb{R}^{16}, \; \hat{y}_{\text{RUL}}, \; \sigma^2_{\text{AMKB}}, \; \mathcal{C}_{\text{explain}}, \; \{\phi_j\}_{j=1}^D \right\rangle$$
4. **Closed-Loop Counterfactual Re-Evaluation**:
   - Evaluates resilience against synthetic extreme stress regimes (rapid thermal runaway, bearing seizure, sensor dropout).
   - If counterfactual simulation breaches safety margins, triggers the `re-evaluate` feedback loop up to $R_{\max}$ retries with stress penalties.
   - Strictly enforces the **DEF-008 Zero-Miss Safety Parity Constraint**:
     $$\text{if } \hat{y} \le 10 \text{ cycles} \quad \text{or} \quad h \le 0.20 \implies a^* \leftarrow \text{REPLACE\_IMMEDIATELY}$$
